# Deep Learning

Deep learning is a subset of machine learning that uses neural networks with multiple layers to learn from data. These deep neural networks can automatically extract hierarchical features from raw input data.

## Key Concepts

- Multi-layer neural networks
- Representation learning
- Feature hierarchy
- End-to-end learning

## Common Architectures

- Feedforward Neural Networks
- Convolutional Neural Networks (CNNs)
- Recurrent Neural Networks (RNNs)
- Transformer Models

## Popular Frameworks

- TensorFlow
- PyTorch
- Keras
- JAX

- ResNet: Deep Residual Learning for Image Recognition
- AlexNet: ImageNet Classification with Deep Convolutional Neural Networks
- VGG: Very Deep Convolutional Networks for Large-Scale Image Recognition
